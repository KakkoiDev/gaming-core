# Movement, keyboard, mouse, touch and gamepads

In a scaffolded starter read actions from input.js: [input-actions](input-actions.md). Outside it, use keyDirection, engine vectors and world/screen conversion. Read the exact pinned reference before copying APIs. Test press, hold, release, blur and restart. Keep touch support explicit rather than assuming keyboard code works on phones.

- [input.js](../starters/input.js) (gaming-core action layer, 1.27.0)
- [shorts input.js](../vendor/littlejs/examples/shorts/input.js) (1.27.2 reference)
- [topDown.js](../vendor/littlejs/examples/shorts/topDown.js)
- [game.js](../vendor/littlejs/examples/platformer/game.js)

Keep copied upstream license notices. Reference availability is not browser verification
of every example. Test the actual host result and report any unsupported features.
