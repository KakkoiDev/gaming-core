# Particles, post-processing and tuning

Check built-in effects before writing shaders. Add feedback after a playable loop. Runtime tweakables are engine plugins, not a separate helper file. Disable costly effects or offer reduced motion when appropriate.

Local reference paths:

- [tweakableGame.html](../vendor/littlejs-ai/templates/tweakableGame.html)
- [tween.js](../vendor/littlejs/examples/shorts/tween.js)
- [game.js](../vendor/littlejs/examples/particles/particleEffects.js)

Read the pinned upstream AGENTS.md/reference for the selected engine before adapting.
Keep copied upstream license notices. Reference availability is not browser verification
of every example. Test the actual host result and report any unsupported features.

No scenarios: tuning guidance; Reduce Motion is verified in the [game kit's scenarios](../starters/kit/SCENARIOS.md).
