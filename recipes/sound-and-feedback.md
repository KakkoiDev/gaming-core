# Sound, music, particles and screen shake

Use engine sounds/helper effects for prototypes. Approved custom WAV assets come from the Pi music workflow; playback starts after a user gesture, with mute/volume. Keep generated score and sample bank in authoring data. Do not regenerate a track to lower volume.

Local reference paths:

- [gameFx.js](../vendor/littlejs-ai/templates/gameFx.js)
- [music.js](../vendor/littlejs/examples/shorts/music.js)
- [particles.js](../vendor/littlejs/examples/shorts/particles.js)

Read the pinned upstream AGENTS.md/reference for the selected engine before adapting.
Keep copied upstream license notices. Reference availability is not browser verification
of every example. Test the actual host result and report any unsupported features.

Scenarios: the audio settings in [the game kit's](../starters/kit/SCENARIOS.md); sounds themselves are not asserted.
